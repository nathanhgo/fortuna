Esta pasta começa vazia de propósito.

Skills são workflows completos e reutilizáveis (podem incluir scripts, referências e templates,
não só texto) para tarefas que se repetem dentro deste projeto específico — por exemplo, "como
adicionar um novo jogo à sala, do zero ao fim" (engine + testes + endpoints + UI + registro no
lobby).

Crie a primeira skill só depois de sentir a dor real de repetir esse processo manualmente
2-3 vezes. Criar skills antecipadamente demais tende a ficar desatualizado e a mentir sobre como
o projeto funciona de fato.
